
# DS Visualizer

An interactive application designed to make core Data Structures intuitive through real-time visual simulation.

## 🚀 Vision

Data Structures are often taught abstractly.
This project transforms them into dynamic, visual experiences where users can *see* how operations manipulate data step-by-step.

Instead of memorizing theory — users build intuition.

---

## 📚 Supported Data Structures

### 🔹 Stack

* Push
* Pop

### 🔹 Queue

* Enqueue
* Dequeue
* Front and rear pointer visualization

### 🔹 Linked List

* Insert 
* Delete
* Traverse
* Node connection visualization

---

## 🎯 Key Features

* Real-time animated operations
* Step-by-step structural updates
* Beginner-friendly interface
* Clean UI focused on conceptual clarity
* Immediate visual feedback after every operation

---

## 🧠 Learning Outcome

Users can clearly understand:

* How elements are stored and removed
* How pointers shift during operations
* The structural difference between linear data structures
* Why certain operations are faster/slower conceptually
